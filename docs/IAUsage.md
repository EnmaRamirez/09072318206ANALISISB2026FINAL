# Informe de utilización de IA

## Prompts enviados
1. "Diseña una API REST en C# para incidentes de red con reglas de negocio, SQLite y pruebas xUnit."
2. "Implementa reglas como máximo 3 incidentes activos por técnico, escalado automático y historial de cambios."
3. "Crea un README con instrucciones de ejecución y despliegue a Render."
4. "Genera historias de usuario con criterios de aceptación medibles."

## Reflexión
La IA ayudó a estructurar la solución, definir la arquitectura del proyecto y proponer reglas de negocio coherentes con la evaluación. Se validó cada parte con pruebas y ajustes manuales para garantizar que la lógica fuera realista y compilable.

## Correcciones realizadas
- Ajuste de paquetes EF Core a versiones compatibles con .NET 8.
- Corrección de expresiones LINQ incompatibles con EF Core.
- Ajuste del flujo de estados para mantener reglas de negocio consistentes.
- Validación de la API con pruebas y arranque local.
